# MeetSync — Сервис управления онлайн-встречами

## Назначение проекта
Веб-приложение для планирования, создания и проведения онлайн-встреч с возможностью управления расписанием и генерацией уникальных ссылок-приглашений.

## Целевая аудитория
* Корпоративные команды для проведения совещаний.
* Преподаватели и репетиторы для онлайн-уроков.
* Обычные пользователи для личного общения.

## Описание предметной области
Система позволяет пользователям регистрироваться, создавать виртуальные "комнаты" для встреч, задавать время начала и длительность, а также отправлять приглашения другим участникам. Предусмотрены различные тарифные планы (бесплатный с ограничениями по времени и премиум).

## Основные сущности (для БД)
1. **Пользователь (User)** — организатор или участник.
2. **Встреча (Meeting)** — запланированное событие (тема, дата, время).
3. **Комната (Room)** — виртуальное пространство со своей ссылкой.
4. **Подписка (Subscription)** — тарифный план пользователя (Free, Premium).

## Основные функции
* Регистрация и авторизация пользователей.
* Создание и редактирование встреч.
* Генерация уникальной ссылки на встречу.
* Подсчет длительности встречи и тарификация.

## План развития проекта
* **ПР1:** Базовые алгоритмы на Python (ветвления, типы данных).
* **ПР2:** Добавление ООП (классы) и сложных структур данных (списки, словари).
* **Django:** Перенос логики в веб, создание моделей БД, реализация интерфейса и API.
