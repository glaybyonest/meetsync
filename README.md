# MeetSync — Сервис управления онлайн-встречами

Консольное приложение для учёта виртуальных комнат (онлайн-залов)
и управления бронированием онлайн-встреч.

## Возможности (ПР2)
- просмотр и поиск виртуальных комнат по подстроке названия;
- проверка вместимости и фильтрация комнат через генератор;
- сортировка комнат по вместимости с использованием `lambda`-функции;
- проверка доступности комнаты на выбранную дату;
- создание и отмена бронирований онлайн-встреч;
- сохранение и загрузка данных в формате JSON (`data/rooms.json`,
  `data/bookings.json`).

## Структура проекта
- `main.py` — точка запуска и интерактивное консольное меню;
- `rooms.py` — функции работы с виртуальными комнатами;
- `bookings.py` — функции создания, отмены и проверки бронирований;
- `storage.py` — загрузка и сохранение данных в JSON через `with open()`;
- `utils.py` — безопасный ввод чисел и дат с перехватом `ValueError`;
- `data/` — JSON-файлы данных (`rooms.json`, `bookings.json`);
- `tests/` — автоматизированные тесты `pytest` (`test_rooms.py`,
  `test_bookings.py`).

## Требования и установка
- Python 3.11+;
- `pytest>=8.0`;
- `flake8>=7.0`.

Установка зависимостей:
```bash
pip install -r requirements.txt
```

## Запуск программы, тестов и линтера
```bash
python main.py
pytest -v
flake8 . --extend-exclude=venv
```
