# MeetSync — Сервис управления онлайн-встречами

## Назначение
MeetSync — сервис для планирования, координации и управления онлайн-встречами,
виртуальными переговорными комнатами и слотами видеоконференций. Приложение
позволяет отслеживать доступность виртуальных залов, проверять их вместимость
по числу участников и бронировать онлайн-комнаты на выбранные даты.

## Целевая аудитория
Распределённые IT-команды, проектные менеджеры, преподаватели и студенты,
которым необходимо организовывать онлайн-встречи, дейли-митинги, вебинары и
командные созвоны без пересечений по расписанию.

## Предметная область
Управление виртуальными комнатами (онлайн-залами Zoom, Google Meet, Teams),
участниками/организаторами встреч и бронированиями слотов онлайн-встреч.
Одна виртуальная комната не может иметь две активные онлайн-встречи на одну
и ту же дату, а число участников не должно превышать лимит вместимости зала.

## Основные сущности
- **Виртуальная комната (Room)** — идентификатор (`id`), название онлайн-зала
  (`name`), максимальное число участников (`capacity`), платформа (`room_type`)
  и описание (`description`).
- **Пользователь / Организатор (User)** — идентификатор (`id`), имя (`name`) и
  электронная почта (`email`).
- **Онлайн-встреча / Бронирование (Booking)** — идентификатор (`id`), выбранная
  виртуальная комната (`room`), организатор (`user`), дата проведения встречи
  (`booking_date`) и статус отмены (`is_cancelled`).

## Основные функции
- `get_booking_status(is_available)` — определение и формирование текстового
  статуса доступности виртуальной комнаты для онлайн-встречи;
- `check_room_capacity(capacity, participants)` — проверка соответствия
  вместимости виртуальной комнаты заявленному числу участников созвона;
- `format_meeting_info(room_name, capacity, meeting_date, participants)` —
  формирование сводной карточки онлайн-встречи с проверкой условий проведения.

## План развития
На следующих этапах планируется:
- перевод данных в коллекции и JSON-файлы, декомпозиция на модули (ПР2);
- переход к объектно-ориентированной модели `Room`, `User`, `Booking` (ПР3);
- создание веб-приложения на фреймворке Django и маршрутизации URL (ПР5);
- перевод веб-интерфейса на шаблоны Django (DTL) и статические файлы (ПР6);
- проектирование реляционной БД SQLite и аналитических SQL-запросов (ПР7);
- подключение Django ORM, форм, аутентификации, REST API и Docker (ПР9–ПР16).
